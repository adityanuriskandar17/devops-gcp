# Junior Full stack Developer Requirements

## Tech Stack yang Digunakan

| Kategori | Teknologi |
|----------|-----------|
| Bahasa | Python |
| Web Framework | Flask, Flask-SocketIO |
| Database | Postgresql, MySQL (mysql-connector-python), Redis |
| Frontend | React / Next, Jinja2 Templates (server-rendered), PWA |
| Deployment | Docker, GCP |
| CI/CD | GitHub Actions |

---

## Kualifikasi Wajib

### 1. Python (Menengah)
- Memahami dasar Python: functions, classes, error handling, list comprehension
- Bisa membaca dan menulis kode Python tanpa panduan step-by-step
- Familiar dengan virtual environment dan `pip`

### 2. Flask (Dasar–Menengah)
- Memahami konsep routing, request/response, Blueprint
- Bisa membuat REST API endpoint (GET, POST)
- Memahami penggunaan decorator
- Familiar dengan Jinja2 templating

### 3. SQL / MySQL (Dasar–Menengah)
- Bisa menulis query: SELECT, INSERT, UPDATE, JOIN, GROUP BY
- Memahami konsep index, primary key, foreign key
- Bisa membaca dan memahami query yang kompleks (subquery, aggregation)
- Familiar dengan tools seperti MySQL Workbench, DBeaver, atau TablePlus

### 4. Git (Dasar)
- Bisa melakukan clone, pull, push, commit, branch, merge
- Memahami flow dasar: buat branch → develop → pull request → merge
- Familiar dengan GitHub

### 5. API & HTTP (Dasar)
- Memahami konsep REST API (endpoint, method, status code)
- Bisa menggunakan Postman atau tools serupa untuk testing API
- Memahami format JSON
- Memahami konsep authentication (API Key, JWT/Bearer Token)

---

## Kualifikasi Nilai Tambah (Nice to Have)

- **Docker**: Bisa membaca Dockerfile, build image, dan run container
- **Google Cloud Platform**: Familiar dengan Cloud Run, Artifact Registry, atau service GCP lainnya
- **Redis**: Memahami konsep key-value store dan caching
- **Linux/CLI**: Nyaman bekerja di terminal, SSH, basic commands
- **Computer Vision / ML**: Pernah bermain dengan OpenCV, face detection, atau library ML
- **WebSocket**: Memahami konsep real-time communication (Socket.IO)
- **CI/CD**: Memahami konsep GitHub Actions atau pipeline serupa

---

## Soft Skills

- **Problem solving**: Bisa mendiagnosa bug dari log/error message
- **Membaca kode orang lain**: Project ini memiliki codebase yang sudah besar, kemampuan membaca dan memahami kode existing sangat penting
- **Komunikasi**: Bisa menjelaskan progress dan blocker dengan jelas
- **Inisiatif belajar**: Mau belajar teknologi baru yang belum dikuasai
- **Dokumentasi**: Terbiasa menulis komentar kode dan dokumentasi sederhana

---

## Tanggung Jawab Utama

1. **Develop & maintain API endpoints** — Membuat endpoint baru dan memperbaiki bug di endpoint yang sudah ada
2. **Database**: Menulis dan mengoptimasi query MySQL, membuat migration sederhana
3. **Integrasi API eksternal** — Membantu integrasi dengan GymMaster API dan service lainnya
4. **Bug fixing** — Mendiagnosa dan memperbaiki bug berdasarkan laporan
5. **Testing** — Melakukan testing API via Postman dan memastikan endpoint berjalan sesuai spesifikasi
6. **Code review** — Berpartisipasi dalam review kode bersama tim
